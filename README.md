# C++ basics (college)

Educational practice in the "C++" programming language
## Содержание

- Ввод/вывод, типы данных
- Условные операторы (`if`, `switch`)
- Циклы (`for`, `while`, `do-while`)
- Функции, перегрузка, рекурсия
- Одномерные и двумерные массивы
- Указатели и ссылки
- Работа со строками (`char`, `std::string`)
- Файловый ввод/вывод
