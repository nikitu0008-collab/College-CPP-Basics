# C++ Basics (college)

Практические задания по базовому курсу C++ в IT TOP COLLEGE: 70 самостоятельных
программ, разложенных по 13 главам — от `Hello, world` до работы с файлами
и препроцессором.

Все файлы в UTF-8, собираются без ошибок и предупреждений:

```bash
g++ -std=c++20 -Wall -Wextra task_1_1.cpp -o task_1_1
./task_1_1
```

## Что внутри

- **Главы 1–5** — базовый синтаксис: типы, ветвления, циклы, функции.
- **Главы 6–9** — работа с памятью: массивы, двумерные массивы, указатели,
  динамическое выделение памяти.
- **Глава 10** — рекурсивные алгоритмы.
- **Глава 11** — массивы, передаваемые в функции по указателю, сортировка
  (пузырьком, выбором), вставка и удаление элементов.
- **Глава 12** — строки: ручные функции над `char[]` (длина, поиск символа,
  разворот, проверка пароля) и `std::string`.
- **Глава 13** — работа с файлами (`std::ifstream` / `std::ofstream`), шифр
  Цезаря, разворот файла и задание на макросы препроцессора.

### Глава 13: макросы вместо ключевых слов

`cross_cross.h` — заголовочный файл на 85 макросов, которые переименовывают
языковые конструкции в русские слова:

```cpp
#define царь_батюшка_главный int main
#define Русь std
#define читать_летопись ifstream
#define зачерпнуть getline
#define для for
#define коли if
#define воздать return
```

```cpp
#include "cross_cross.h"

царь_батюшка_главный() {
    Русь::читать_летопись файл("task_13_8_student.txt");
    Русь::string ФИО;
    Русь::зачерпнуть(файл, ФИО, '\n');
    Русь::молвить << "Студент: " << ФИО << Русь::прыг_скок;
    воздать 0;
}
```

Заодно это хороший пример того, как работает препроцессор: директива
`#define` подставляет текст до компиляции, поэтому код с такими именами
остаётся валидным C++.

## Сборка всех заданий

```bash
find . -name '*.cpp' -print0 | while IFS= read -r -d '' f; do
  out="/tmp/$(basename "${f%.cpp}")"
  g++ -std=c++20 -Wall -Wextra "$f" -o "$out" || echo "FAIL: $f"
done
```

На Windows:

```powershell
Get-ChildItem -Recurse -Filter *.cpp | ForEach-Object {
  g++ -std=c++20 -Wall -Wextra $_.FullName -o "$env:TEMP\$($_.BaseName).exe"
  if ($LASTEXITCODE -ne 0) { "FAIL: $($_.FullName)" }
}
```

## Кодировка

Исходники в UTF-8, поэтому в программах вызывается `chcp 65001` — иначе
кириллица в консоли Windows превратится в мусор. Файл `cross_cross.h`
переключает кодовую страницу сам.
